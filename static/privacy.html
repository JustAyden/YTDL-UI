Privacy

What this YTDL-UI server does with your data. This page is generated from the server's current settings, so it describes this server — not just the software in general.

boltThe short version

  • No accounts, ads, analytics or tracking.
  • The server sees the links you paste and your IP address, and uses them only to run your downloads and to stop abuse.
  • Files downloaded on the server are deleted {{ttl}} after they finish, or as soon as you remove them from your list.
  • Your settings and download list are stored in your browser, not on the server.
{{notes}}

downloadWhat the server receives

  • The link you paste and the options you pick (format, quality, which playlist items), so it can look up and download the media. They're kept in memory with the download and deleted with it.
  • Your IP address, which every website receives. YTDL-UI uses it to rate-limit requests and to cap how many downloads one visitor can run at once. It's kept in memory only — for about a minute for rate limits, and with each server download until that download is deleted — and forgotten when the server restarts.
  • Failed sign-ins. If a wrong password is entered (site or admin), your IP address and the number of failed attempts are saved on the server's disk, so lockouts survive a restart. The entry is removed when you sign in successfully, or a day after the last failed attempt once any lockout has ended.

devicesWhere your downloads are processed

{{mode}}

On the server

The media is downloaded to the server's disk, converted there, and kept until you save it. Finished files are deleted {{ttl}} after they finish. Cancelled and failed downloads are deleted straight away, and removing a download from your list deletes it immediately.

On your device

The server only asks yt-dlp which streams to fetch. Your browser downloads and converts them, and the finished file never touches the server's disk.

historyWhat gets logged

YTDL-UI doesn't keep an access log of the pages you open or the requests you make. Its log records:

  • each download processed on the server: format, quality and {{log_line}};
  • error messages when a download fails, which can include the video's ID on that site;
  • admin sign-ins, failed sign-ins and lockouts, with the IP address.

Where that log is kept, and for how long, is up to whoever runs this server.

admin_panel_settingsWho can see it

  • This server's admin can see the downloads currently on the server — title, site, format and the IP address that started each one — until they're deleted, plus any locked-out IP addresses.
  • YTDL-UI is open-source software. Its authors don't run this server and receive no data from it.

languageOther services involved

Your browser may contact

This server contacts

  • The media site, through yt-dlp{{via_proxy}}, to look up and download what you asked for. The site sees this server's IP address, not yours.
  • GitHub and the Python Package Index, to check for and download updates to YTDL-UI, yt-dlp and ffmpeg. No visitor data is included.

lockCookies and storage on your device

{{cookie}}

Your browser also keeps these in its local storage for this site. They stay on your device — only download IDs are sent back, to check on a download's progress:

  • your theme, color and other Settings;
  • your last-used format and quality;
  • your list of recent server downloads (up to 30: title, thumbnail link, format), so it survives a reload.

Settings → Clear download list removes the list. Clearing this site's data in your browser removes everything.
